# Contribuindo com o SCANNY

Obrigado por contribuir. O projeto prioriza segurança, transparência e reversibilidade.

## Antes de abrir um pull request

- Explique o problema e a solução;
- Rode os testes do protótipo;
- Não inclua comandos externos baixados em tempo de execução;
- Não adicione limpeza de caminhos sem uma lista permitida;
- Não remova confirmações de ações destrutivas;
- Atualize a documentação quando uma ação nova for adicionada.

## Alterações no Windows

Qualquer código que futuramente altere o Windows deve separar análise, prévia, confirmação, execução, verificação, log e restauração. A ação deve declarar seu nível de risco e o comportamento quando um arquivo ou configuração estiver em uso.

## Pull requests

Use uma descrição clara, inclua evidências de teste e informe se a alteração afeta somente a interface ou também o sistema operacional.
